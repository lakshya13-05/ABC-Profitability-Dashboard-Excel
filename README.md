# ABC Executive Summary & Profitability Dashboard

## Project Overview
An interactive Excel-based business analytics dashboard developed to analyze sales performance, revenue, gross profit, and business profitability.

The project transforms raw sales data into meaningful business insights through data analysis and visualization.

## Tools & Technologies
- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Formulas
- Data Visualization

## Dataset
The dataset contains approximately 2,707 sales records covering:
- Order Date
- Region
- Country
- Sales Channel
- Product Category
- Units Sold
- Revenue
- Cost of Goods Sold (COGS)
- Gross Profit
- Gross Margin

## Key Performance Indicators (KPIs)
- Total Revenue
- Gross Profit
- Gross Profit Margin
- Units Sold
- Total Orders

## Dashboard Features
- Executive Summary
- Monthly Revenue Analysis
- Gross Profit Analysis
- Country-wise Performance
- Region-wise Analysis
- Sales Channel Analysis

## Key Learnings
- Data Cleaning and Organization
- Business Data Analysis
- PivotTables and PivotCharts
- KPI Development
- Dashboard Design
- Data Visualization
